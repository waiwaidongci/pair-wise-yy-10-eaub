# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付、返修。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。
- 画廊寄卖：仅待交付且无缺陷的作品可签寄卖单（画廊、起止日期、售价、佣金率），同一作品同时只能占一张未结束寄卖单；撞档期时指出原单，新单不落账。
- 售出按成交额 ×（1 − 佣金率）登记作者应收；售后退回登记损坏、作品转返修，原应收转待冲销。

代码分层：
- `consignment.js`：寄卖判定（能否签约、档期占用、单据状态），纯逻辑，不碰页面和存储。
- `ledger.js`：账本（应收登记、转待冲销、合计），纯逻辑，不碰页面和存储。
- `index.html`：页面渲染、事件接线与 localStorage 持久化。
