# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付，以及寄卖退回后的返修、已售出。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

画廊寄卖与分账：
- 待交付且无缺陷的作品才能签寄卖单，且同一时间只签一张未结束寄卖单；单上写清画廊、起止日期、售价和佣金比例。
- 档期被其他画廊占住时指出原单（画廊、起止、售价、佣金），保存不落账。
- 售出登记成交额，按成交额 − 佣金自动生成「作者应收」入账。
- 售后退回需登记损坏，作品回到返修列，原应收转为待冲销，可再确认冲销。
- 寄卖判定（`js/consignment.js`）、账本（`js/ledger.js`）、页面（`js/consignment-ui.js`）各自分开；原筛选与作品导出保持不变，账本可单独导出 JSON。
